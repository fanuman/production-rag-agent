# Production RAG agent

Month 1 capstone project - an agent-powered RAG chatbot, deployed on AWS with
CI/CD, a JS frontend, logging/monitoring, and evaluation metrics.

Builds up week by week rather than being rewritten each time - check the tags
below to see it evolve from a basic chatbot into a deployed system.

## Tech stack
- Python, FastAPI
- LangChain, OpenAI API
- Vector DB: (Chroma locally -> Pinecone/pgvector)
- Docker
- AWS (Lambda / EC2, API Gateway, CloudWatch, Secrets Manager)
- GitHub Actions (CI/CD)
